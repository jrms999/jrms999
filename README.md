# John Sutherland

Royal Marines veteran based in Glasgow, Scotland. I build practical software at the intersection of accessible services, operations, safety, and data. My career has included autonomous vehicle testing, rail operations, IT infrastructure, and customer-facing leadership.

I am developing projects in LawTech, music technology, and veteran support. The repositories below are works in progress; each README describes what is implemented today and what comes next.

## Current projects

- **[LegalHub](https://github.com/jrms999/LegalHub)** — an early guided claim-intake prototype using FastAPI and Next.js. The local Scotland flow generates a draft summary, item list and timeline; England-and-Wales document templates remain placeholders. This is a local demo, not a filing service.
- **[PedalScan](https://github.com/jrms999/PedalScan_app)** — an Expo and FastAPI prototype for photographing guitar pedals. Recognition and pricing are planned; the current flow demonstrates image upload.
- **[Resonance](https://github.com/jrms999/Resonance)** — a Python backend prototype exploring music streaming, engagement, and rewards.
- **[SVR Support App](https://github.com/jrms999/svr-support-app)** — a resident-support PWA concept for veterans' housing, with demo content and no live resident data.

## How I work

I bring a safety and operations perspective to product design: define a clear user journey, test the difficult cases, document limitations, and make the next improvement measurable. I am especially interested in accessible legal tools, cybersecurity, responsible AI, and services that help veterans navigate everyday systems.

**Technical interests:** Python, TypeScript, FastAPI, React/Next.js, Linux, data analysis, and cloud infrastructure.
